# Asset Taxonomy

Everything that must exist to run a course. Two tiers: Platform (built once, shared) and
Course (built per course). A third tier — Runtime — is generated per-student automatically.

**Generation key:**
- `human` — must be created by a human
- `ai` — fully AI-generated (no human needed)
- `ai → human` — AI drafts, human reviews/approves
- `human records` — human performs the action (e.g., records a video)
- `runtime` — generated per-student by AI during the course

## Summary: Human vs. AI Effort

| Category | Human Required | AI Does Heavy Lifting |
|---|---|---|
| Core course strategy | ICP, start/end state, schedule | Everything else (AI proposes, human approves) |
| Recorded assets | Transmission videos, voice clone samples | Scripts, summaries, audio versions |
| All prompts | Review + approve | Draft all |
| All copy | Review + approve | Draft all |
| Material schemas | Decide what materials exist | Draft schemas + generation prompts |
| Marketing | Testimonials, pricing, CTA | All copy, email sequences |
| Community | Guidelines, manual posts | Discussion prompts, celebration posts |
| Integrations | GHL + Skool configuration | N/A |
| All runtime student assets | Nothing | Everything |

**Rough ratio: ~10-15% human input unlocks 100% of the course.**
Most of that human input is strategic decisions and recorded video — not writing.
